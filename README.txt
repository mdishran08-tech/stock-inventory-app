আমার স্টক ম্যানেজার — ওয়েবসাইট + ইনস্টলযোগ্য মোবাইল অ্যাপ (PWA)

ফিচার:
- পণ্য যোগ, সম্পাদনা ও মুছে ফেলা
- পণ্য কোড/বারকোড সংরক্ষণ
- সমর্থিত ব্রাউজারে ক্যামেরা দিয়ে বারকোড স্ক্যান
- স্টক সংখ্যা ও কম স্টকের হিসাব
- সার্চ, JSON Export/Import ব্যাকআপ
- PWA হিসেবে ফোনের Home Screen-এ ইনস্টল করা যায়

প্রকাশ:
1. ZIP extract করুন।
2. সব ফাইল একসঙ্গে Netlify-তে deploy করুন (index.html, manifest.webmanifest, sw.js, icon.svg)।
3. প্রকাশিত HTTPS ওয়েবসাইট Huawei ফোনের Chrome/সমর্থিত ব্রাউজারে খুলুন।
4. “অ্যাপ ইনস্টল” বোতাম অথবা ব্রাউজার মেনু > Add to Home screen / Install app চাপুন।

গুরুত্বপূর্ণ:
- এটি ইনস্টলযোগ্য PWA; আলাদা Android APK নয়।
- পণ্যের ডেটা এখন এই ডিভাইসের ব্রাউজারে থাকে। অন্য ফোনে একই ডেটা শেয়ার, অনলাইন লগইন/সিঙ্ক করতে হলে backend/database যোগ করতে হবে।
- বারকোড ক্যামেরা স্ক্যানের জন্য HTTPS এবং camera permission দরকার; সব ব্রাউজারে BarcodeDetector সমর্থিত নয়।
- Export দিয়ে নিয়মিত backup রাখুন।
